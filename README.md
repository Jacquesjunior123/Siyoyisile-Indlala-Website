# Siyoyisile Indlala Community Farm Web Application

An interactive, responsive website for Siyoyisile Indlala Community Farm, featuring community services, structured enquiries, and interactive JavaScript functionality.

- **Live Production Site:** Pending Netlify deployment
- **Repository:** https://github.com/Jacquesjunior123/Siyoyisile-Indlala-Website

---

## Part 2 Feedback Integration & Historical Changelog

The following improvements were made to address website usability, responsiveness, and repository maintenance requirements.

### 1. Interactive Interface States

- Added interactive hover, focus, active, and visited states to improve navigation and usability.
- Improved visual feedback for interactive links and form controls.

### 2. Responsive Layout and Typography

- Used relative CSS units and fluid sizing where appropriate.
- Implemented media queries for tablet and mobile screen sizes.
- Applied responsive image styling to help prevent horizontal overflow.

### 3. Repository Version Tracking

- Maintained the project in GitHub to track website files and changes.
- Continued development using the existing project structure.

## Part 3 Enhancements Log

### Section 2.1 — Interactive Website Features

- **Interactive Accordions:** Added JavaScript functionality to expand and collapse content.
- **Lightbox Gallery:** Added image preview functionality with a backdrop and keyboard support.
- **Interactive Map:** Integrated a Leaflet-based map with a location marker, subject to successful map loading.

### Section 2.2 — Dynamic Content

- **Service Filtering:** Implemented a search feature that filters service cards based on user input.

### Section 3 — Search Engine Optimisation (SEO)

- Added a `robots.txt` file to provide crawler instructions.
- Added a `sitemap.xml` file listing the website's main pages.
- Added page-level meta descriptions where implemented.
- The sitemap and robots configuration must be updated with the final production URL after deployment.

### Section 4.1 — Enquiry Form Validation

- Implemented client-side JavaScript validation for enquiry form fields.
- Added inline error messages and visual feedback for invalid entries.
- Displayed a confirmation-style message when the form passes client-side validation.
- Actual email delivery and server-side form submission remain pending configuration.
